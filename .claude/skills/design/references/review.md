# Checklist ก่อนบอกว่าเสร็จ

เดินทีละข้อจริง ๆ ข้อไหนทำไม่ได้ให้บอกว่าข้าม ไม่ใช่เงียบ

## หน้าตาและความสม่ำเสมอ
- [ ] สีทุกค่าเป็น `var(--mat-sys-*)` หรือ `color-mix` จาก token — `grep -nE "#[0-9a-fA-F]{3,6}|rgb\(" venue/web/src/app` ไม่ควรเจอของใหม่
- [ ] ขนาดตัวอักษรทุกที่มาจาก `font: var(--mat-sys-…)` ไม่มี `font-size` ลอย และไม่มี `font-weight` นอกจาก 400/500
- [ ] ไม่มีฟอนต์ใหม่ ไม่มี `@import` ไปหา Google Fonts ไม่มี icon font/emoji แทนไอคอน
- [ ] ระยะห่างเป็นทวีคูณ 0.25rem และใช้ primitive (`.stack` `.row` `.columns` `.entry`) แทนการเขียน flex/grid ซ้ำ
- [ ] ไม่มีรายการใน "AI slop ที่ห้ามผลิต" ใน SKILL.md หลุดเข้ามา

## เนื้อหาและภาษา
- [ ] ทุกข้อความผ่าน `i18n.t()` และมีกุญแจครบทั้ง `th.json` และ `en.json` (จำนวนกุญแจสองไฟล์เท่ากัน)
- [ ] สลับเป็นอังกฤษแล้ว layout ไม่แตก (ข้อความยาวขึ้น) และสลับเป็นไทยแล้วสระ/วรรณยุกต์ไม่ถูกตัด
- [ ] วันที่ทุกที่ผ่าน `appDate` และขึ้นปี พ.ศ. ในภาษาไทย
- [ ] ไม่มี placeholder ค้าง (Lorem ipsum, TODO, ข้อความอังกฤษในหน้าไทย)

## สถานะที่ไม่ใช่ทางสุข
- [ ] ตอนโหลด / ว่างเปล่า / ผิดพลาด / ไม่มีสิทธิ์ ออกแบบไว้แล้ว ไม่ใช่หน้าขาว
- [ ] error จาก API แปลจาก `code` เป็นข้อความผ่าน i18n (ห้ามโชว์ข้อความจาก backend ตรง ๆ)
- [ ] ข้อมูลยาวผิดปกติ (ชื่อสนามยาว ๆ, คอร์ท 20 คอร์ท, ราคา 6 หลัก) ไม่ทำให้ล้นจอ

## เข้าถึงได้
- [ ] ปุ่มทุกตัวกดด้วยคีย์บอร์ดได้และเห็น focus ring
- [ ] ปุ่มที่มีแต่สัญลักษณ์มี `aria-label` (แปลแล้ว) · disclosure มี `aria-expanded` + `aria-controls` · toggle มี `aria-pressed`
- [ ] เป้าการกดบนมือถือ ≥ 44px
- [ ] คอนทราสต์ตัวหนังสือกับพื้นผ่าน 4.5:1 (คู่ token `on-*` ผ่านอยู่แล้ว — ที่พังคือตอนผสมสีเอง)
- [ ] `prefers-reduced-motion` ถูกเคารพ
- [ ] ลำดับหัวข้อ (h1→h2→h3) ไม่ข้ามขั้น และ landmark (`main`/`nav`) ถูกต้อง

## ทดสอบ
- [ ] `cd venue/web && npm test -- --watch=false` ผ่าน และมี test ใหม่ครอบสิ่งที่เพิ่ม
- [ ] `npm run format` แล้ว `npm run build` ไม่มี budget warning ใหม่ (component style 4 kB / initial 500 kB)
- [ ] element ที่ test ต้องจับมี `data-testid` และอ่าน control จริงผ่าน `switchIn()`/`controlOf()` ไม่ใช่อ่าน `.checked` จาก host
- [ ] เปิดของจริงแล้ว: `python scripts/verify/<flow>.py` ผ่าน หรือขับด้วย `webapp-testing`
- [ ] screenshot 4 ใบ (390px / 1280px × ไทย / อังกฤษ) แนบไว้ในคำตอบและ PR
