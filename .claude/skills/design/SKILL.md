# ออกแบบหน้าจอ CourtPaka

แอปนี้มีตัวตนอยู่แล้ว งานออกแบบคือการต่อจากของที่มี ไม่ใช่เริ่มใหม่ทุกครั้ง
อ่าน `references/tokens.md` ก่อนเขียน CSS บรรทัดแรก และใช้ `references/review.md` ก่อนบอกว่าเสร็จ

## ลำดับการทำงาน

1. **เขียน design brief สั้น ๆ ก่อนแตะโค้ด** (3–5 บรรทัด ใส่ไว้ในคำตอบ ไม่ต้องสร้างไฟล์)
   - หน้านี้ทำให้ใครทำอะไรสำเร็จ และอะไรคือสิ่งเดียวที่ต้องเด่นที่สุดบนจอ
   - ผู้ใช้เข้ามาจากไหน บนมือถือหรือจอคอม (ฝั่งผู้จอง = มือถือก่อน · ฝั่งเจ้าของสนาม = จอคอมก่อน แต่ต้องไม่พังบนมือถือ)
   - ต่อยอดจากหน้าไหนที่มีอยู่ (ชื่อไฟล์) และจะ **ไม่** ให้หน้าตาเป็นแบบไหน
   - ถ้า brief เขียนไม่ได้เพราะ requirement ไม่ชัด ให้ถามก่อน (CLAUDE.md > วิธีทำงาน)
2. **สำรวจของที่มีก่อนสร้างของใหม่** — `frontend/src/styles.scss` มี primitive ครบชุดแล้ว (`.shell` `.stack` `.row` `.columns` `.entry` `.badge` `.field` `.muted`)
   และหน้าที่ใกล้เคียงมักแก้ปัญหาเดียวกันไปแล้ว: `login.page.scss` (หน้าเต็มจอสองฝั่ง), `availability.page.scss` (ตาราง court × ชั่วโมง), `app.scss` (บาร์ + เมนูมือถือ)
3. **เลือกส่วนประกอบโดยคิดราคา** — Material module ที่ยังไม่มีในแอปมีต้นทุน bundle จริง
   แอปตั้งใจไม่ใช้ `MatMenu` (16 kB gzipped สำหรับพับลิงก์ 4 อัน — ดูคอมเมนต์ใน `app.html`) และไม่ใช้ icon set เลย
   สิ่งที่มีอยู่แล้ว: `MatCard` `MatButton` `MatFormField/MatInput` `MatProgressBar` `MatCheckbox` `MatDatepicker` `MatSlideToggle` `MatToolbar`
4. **เขียน** ตามกฎด้านล่าง คอมเมนต์ SCSS บอก *เหตุผล* ของ layout เหมือนไฟล์อื่นในโปรเจกต์ (ทำไมถึงพับ ทำไมถึงไม่ใช้ component นั้น) ไม่ใช่บอกว่าโค้ดทำอะไร
5. **ตรวจจริง** (ดู "Verify" ด้านล่าง) — งาน UI ที่ยังไม่เคยเปิดดูบนเบราว์เซอร์ ถือว่ายังไม่เสร็จ
6. **เดิน checklist** ใน `references/review.md`

## กฎของโปรเจกต์นี้ (ห้ามฝ่าโดยไม่ถาม)

- **สีมาจาก token เท่านั้น** — `var(--mat-sys-*)` ห้ามเขียน hex/rgb ใหม่ในโค้ดหน้าจอ ถ้าต้องการน้ำหนักสีที่ต่างออกไป ใช้ `color-mix(in srgb, var(--mat-sys-tertiary) 28%, transparent)` (แบบที่ `login.page.scss` ทำ) ไม่ใช่สีใหม่
- **ตัวอักษรมี 2 น้ำหนักเท่านั้น: 400 กับ 500** — `styles.scss` ส่ง Noto Sans Thai แค่สองน้ำหนักนี้ เขียน `font-weight: 300/600/700` แล้วเบราว์เซอร์จะปลอมให้ (หนาเบลอ/บางเฟค) ห้ามเพิ่มฟอนต์ ห้ามใช้ Google Fonts ผ่าน `@import`
- **ขนาดตัวอักษรมาจาก type scale** — ใช้ `font: var(--mat-sys-title-medium)` ทั้งก้อน (ได้ family/size/weight/line-height ที่คู่กัน) ไม่ตั้ง `font-size` ลอย ๆ
- **ไม่มี icon set** — ถ้าต้องมีสัญลักษณ์ วาดด้วย CSS (แบบ `.hamburger` ใน `app.scss`) หรือ inline SVG เล็ก ๆ ห้ามลง icon font / lucide / material-icons และห้ามใช้ emoji แทนไอคอน
- **ข้อความทุกตัวผ่าน i18n** — `i18n.t('...')` พร้อมกุญแจใน `core/i18n/th.json` **และ** `en.json` ทั้งคู่ · `aria-label` ก็ต้องแปล · วันที่ใช้ `{{ v | appDate: i18n.locale() }}` ห้าม `DatePipe`
- **โหมดสว่างอย่างเดียว** — `html { color-scheme: light; }` อย่าแอบใส่ dark mode ครึ่งทาง ถ้าจะทำต้องทำทั้งแอปและถามก่อน
- **ทุกอย่างที่ test แตะต้องมี `data-testid`** บน host element (Material ซ่อน control จริงไว้ข้างใน — ใช้ `switchIn()`/`controlOf()` ใน `testing/dom.ts`)
- **สไตล์ของหน้าหนึ่งอยู่ในไฟล์ของหน้านั้น** ถ้าเริ่มใช้ซ้ำ 3 ที่ ย้ายขึ้น `styles.scss` · component stylesheet เกิน 4 kB จะ warn ตอน build

## ภาษาไทยเปลี่ยนการออกแบบยังไง

- ไทยมีสระบนล่างและวรรณยุกต์สองชั้น → อย่าบีบ `line-height` ต่ำกว่าที่ token ให้มา และอย่าตัดบรรทัดด้วย `height` คงที่
- **ห้าม `text-transform: uppercase` และ `letter-spacing` กับข้อความไทย** — ไทยไม่มีตัวพิมพ์ใหญ่ และการถ่างช่องไฟทำให้สระลอยออกจากพยัญชนะ
- ไทยไม่เว้นวรรคระหว่างคำ → คอลัมน์แคบ ๆ จะตัดคำผิดที่ ให้ใช้ความกว้างที่พออ่าน (`max-width: 28ch` ขึ้นไปสำหรับย่อหน้า) และอย่าใช้ hyphenation
- ข้อความไทยกับอังกฤษยาวไม่เท่ากัน (ต่างได้ 20–30%) → ปุ่มและหัวตารางต้องยืดได้ ห้ามกำหนดความกว้างตายตัวให้พอดีข้อความไทยเป๊ะ ๆ **ต้องสลับดูทั้งสองภาษา**
- ปี พ.ศ. ยาวกว่า ค.ศ. และเดือนไทยเต็มยาวมาก → เผื่อที่ให้วันที่ในทุก layout

## AI slop ที่ห้ามผลิต

บอกตัวเองว่า "อย่าทำให้ดูเหมือน AI" ไม่ได้ผล ต่อไปนี้คือรายการที่ห้ามโดยเฉพาะ:

- gradient ม่วง-น้ำเงิน, glassmorphism (`backdrop-filter` + ขอบขาวจาง), เงาเรืองแสงรอบการ์ด, ข้อความไล่สีรุ้ง
- hero ตรงกลางจอ + หัวเรื่องใหญ่สุด + ปุ่มคู่ "เริ่มใช้งาน / ดูเดโม" ที่ไม่ได้พาไปไหน
- ตารางการ์ด 3 ใบเท่ากันเป๊ะ (bento grid) ที่เนื้อหาไม่ได้มีสามอย่างจริง ๆ
- emoji เป็นไอคอนหัวข้อ (🎾 🚀 ✨) และ badge "AI-powered"
- ฟอนต์ที่แอปไม่ได้ส่ง (Inter, Roboto, Space Grotesk) หรือเรียก Google Fonts จากภายนอก
- animation ตอนโหลดหน้าที่ทำให้ต้องรอ, parallax, scroll-jacking, การ์ดที่เด้งขึ้นทีละใบ
- ข้อความ placeholder ภาษาอังกฤษปนในหน้าไทย ("Lorem ipsum", "Your subtitle here")

## Verify

```bash
cd frontend && npm test -- --watch=false     # unit + component tests
npm run format                                # prettier
npm run build                                 # budget: initial 500 kB warn, component style 4 kB warn
```

แล้วเปิดของจริง:

```bash
docker compose --profile full up -d --build   # จาก root ของ repo
python scripts/verify/booking_grid.py         # หรือ script ของ flow ที่แก้ (ดู scripts/verify/README.md)
```
